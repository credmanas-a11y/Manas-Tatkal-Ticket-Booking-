* Automated clicks and navigation on the IRCTC website
* Customizable settings for personalized usage
* Streamlined booking process
* Local browser-based operation

## Installation

Follow these steps to install the IRCTC Tatkal Booking Chrome Extension:

1. Download the latest extension files from the [Releases](../../releases) page.

2. For **version v6.0.0 and later**, download the corresponding asset file, such as `v6.0.0-alpha.zip`.

3. Extract the downloaded ZIP file to a folder on your computer.

4. Open **Google Chrome**.

5. Navigate to:

   ```text
   chrome://extensions/
   ```

6. Enable **Developer mode** using the toggle in the top-right corner.

7. Click **Load unpacked**.

8. Select the folder containing the extracted extension files.

9. The extension should now appear in your Chrome extensions list.

> **Having trouble installing?**
> Please refer to [Discussion #59](../../discussions/59), where detailed installation instructions with images are provided.

## Usage

Once the extension has been installed:

1. Open Google Chrome.
2. Navigate to the official IRCTC website.
3. Open the extension from the Chrome extensions menu.
4. Configure the required settings.
5. Use the extension to streamline the Tatkal booking workflow.

Please use the extension responsibly and in accordance with IRCTC's terms and applicable rules.
